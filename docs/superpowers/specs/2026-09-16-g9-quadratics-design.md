# G9 Quadratics Sheet — Design Spec (2026-09-16)

## Scope (Egypt 2026-2027 FirstTerm, G9-08 → G9-16)

- IN: G9-08 standard form, G9-09 vertex form, G9-10 vertex/axis, G9-11 graph, G9-12 max/min, G9-13 calculator table, G9-14/15/16 real zeros algebraic + applied.
- OUT: discriminant classification (Δ>0/=0/<0 is G10), ball/projectile stories, single-term cancellation, dividing by x.
- Language: English only. Running function for chain: f(x)=x²-2x-3.

## Chain (each block feeds next)

1. Standard form: identify a,b,c.
2. Vertex form + vertex/axis: x=-b/2a, complete square.
3. Graph: value table x=-2..4 + empty CeTZ axes -4..5, student plots.
4. Max/min + zeros: min/max = k, zeros by factoring, y-intercept = c.

## Block pattern (repeat)

- RULE box (2-3 short lines, one centered math line).
- Worked example (4 steps max, I-Do two-column step/voice).
- 2 Try-Its exam-style: MCQ (4 opts) + Complete/Essay past-paper level (Prep 3 Term 1: choose, complete, graph-plot).
- No steps in key — final answers only, last page.

## Graph spec (drawable)

- Value table with blank y column for student.
- CeTZ: light grid 0.5 step, axes with arrowheads, integer ticks -4..5, labels anchored (never floating text), parabola NOT drawn.

## Past-paper level (new curriculum, infer from bank)

- Mix 2 easy / 2 med / 1 hard per block set; full sheet ramps drill → complete → essay graph.
- Contexts: pure + number/rectangle only. No ball.
