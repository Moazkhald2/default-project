# Coding Style Rules

## General
- Use TypeScript strict mode for JS/TS projects
- Prefer const over let, never use var
- Use meaningful names — avoid abbreviations
- Functions under 50 lines, files under 500 lines
- Single responsibility: one file = one concept

## Formatting
- Use consistent indentation (2 spaces for JS/TS, 4 for Python)
- No trailing whitespace
- One blank line between functions/classes
- Max line length: 100 characters

## Imports
- Group: built-in → external → internal
- No unused imports
- Prefer named exports over default exports
