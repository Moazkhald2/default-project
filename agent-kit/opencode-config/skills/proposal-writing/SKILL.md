# Proposal Writing for Math Tutoring

Skill for writing tutoring proposals and contracts that convert prospects into clients.

## When to Use

- User needs to write a proposal for a potential client
- User needs a tutoring contract template
- User is submitting a proposal to a school or organization
- User needs to customize a proposal for different client types
- User wants a follow-up sequence after sending a proposal

## Proposal Structure

Every proposal should follow this structure:

```
1. Problem Statement    — "Here's what I understand about your situation"
2. Approach             — "Here's how I'll help solve it"
3. Outcomes             — "Here's what you can expect"
4. Investment           — "Here's the cost"
5. Next Steps           — "Here's what to do now"
```

### Template

```
# Tutoring Proposal for [Client Name]

## Introduction
[Brief personal intro — who you are, your experience, why you're excited to help]

## Understanding Your Needs
[Restate the challenges the student is facing, based on discovery call]
- [Challenge 1]
- [Challenge 2]
- [Goal]

## My Approach
[How you will address each challenge]
- Initial assessment to identify exact gaps
- Customized lesson plan targeting weak areas
- Regular progress checks and adjustments
- [Teaching methodology highlights]

## Outcomes
[Realistic expectations]
- In [timeframe], student will have mastered [specific skills]
- Expected grade improvement: [X]
- [Other specific outcomes]

## Investment
Package options:

Option 1: Standard — Weekly Sessions
- [X] sessions per week
- [X] minutes per session
- Rate: $[X]/session
- Total/month: $[X]

Option 2: Intensive — Exam Prep
- [X] sessions per week
- Includes practice tests and review
- Rate: $[X]/session
- Total/month: $[X]

Option 3: Premium — Full Support
- [X] sessions per week
- Homework support between sessions
- Priority scheduling
- Weekly parent updates
- Rate: $[X]/session
- Total/month: $[X]

## Schedule
[Proposed weekly schedule]
- Day: [Day], Time: [Time]
- [Alternate if needed]

## Next Steps
1. Review this proposal
2. Reply with any questions
3. Book your first session here: [Calendly link]
4. Sign the agreement: [DocuSign / attached]

I'm excited to help [Student Name] succeed in math!

Best,
[Your Name]
[Phone]
[Email]
[Website]
```

## Client Education Level Customization

### K-12 (parent is decision-maker)

**Focus on:**
- Grade improvement
- Confidence building
- Homework help
- Test preparation
- Communication with parents

**Proposal language:**
```
I understand that [Student] has been struggling with [specific topic]
and it's affecting their confidence in math class. My approach is to
build their skills step by step while also building their belief that
they CAN do math.

You can expect weekly progress updates so you always know where your
child stands and what we're working on.
```

### College student (student is decision-maker)

**Focus on:**
- Specific course performance
- Understanding difficult concepts
- Exam preparation
- Flexible scheduling
- Value for money

**Proposal language:**
```
You're taking [Course Name] and need to understand [concepts] to
succeed in the course. I'll help you break down these concepts
into manageable pieces and prepare you for your exams.

Sessions are flexible around your class and work schedule.
We can adjust focus as needed based on upcoming assignments and tests.
```

### Adult learner (professional development)

**Focus on:**
- Applied, practical knowledge
- Self-paced learning
- Respect for experience
- Clear, measurable progress
- Efficiency

**Proposal language:**
```
You're looking to build [specific math skills] for [professional
goal]. My approach is practical and efficient — we focus on what
you actually need, not abstract theory. We'll work at your pace
and adjust based on your progress.
```

## Group Tutoring Proposals

### Small group (2-5 students)

```
Group Tutoring: [Subject]

Group size: [2-5] students
Duration: [X] sessions, [X] minutes each
Rate: $[X]/student/session (vs $[X] for private)
Total: $[X]/student for the package

Structure:
- [X] minutes of group instruction
- [X] minutes of individual work with support
- [X] minutes of group problem-solving

Benefits over private:
- Students learn from each other's questions
- Collaborative problem-solving
- Lower cost per session
- Builds peer accountability
```

### School/district contracts

```
## Proposal for [School Name]

### Program Overview
[Summary of proposed tutoring program for X students over X weeks]

### Curriculum Alignment
- Aligned with [state standards / school curriculum / specific courses]
- Diagnostic pre-test and post-test
- Progress reports at [weekly/bi-weekly] intervals

### Logistics
- Format: [Online / In-person]
- Location: [School / Remote]
- Schedule: [Days, times]
- Duration: [Start date] — [End date]
- Group size: [X] students per group

### Pricing
- Per-student rate: $[X]/session
- Number of sessions: [X]
- Total cost: $[X]
- Invoicing: Monthly via [method]

### Deliverables
- Pre-assessment and post-assessment results
- Progress reports for each student
- Final summary report
- Teacher consultation sessions
```

## Contract Essentials

### Contract template

```
# Tutoring Agreement

This agreement is between [Tutor Name] ("Tutor") and
[Client Name] ("Client") on behalf of student [Student Name].

## 1. Services
Tutor agrees to provide [subject] tutoring to Student.
Sessions will be [X] minutes per session, [X] times per week.

## 2. Schedule
Sessions will be held on [days] at [time].
Location: [address / online platform].

## 3. Payment
Rate: $[X] per session.
Payment terms: [due at session / weekly / monthly / upfront].
Payment methods: [Venmo / Zelle / PayPal / check].
Late payment: [fee or policy].

## 4. Cancellation
[X] hours notice required for cancellation.
Late cancellation: [full charge / partial charge / no charge].
Make-up sessions: [available / not available, or limit].

## 5. Term
This agreement begins on [start date] and continues
until terminated by either party with [X] days written notice.

## 6. Liability
Tutor is not responsible for student's academic outcomes.
Tutor will provide professional tutoring services but
cannot guarantee specific grades or test scores.

## 7. Photo/Testimonial Release
[Optional] Client agrees to allow Tutor to use (anonymized)
progress results and testimonials for marketing purposes.

Signed:
Tutor: ___________________   Date: ___________
Client: __________________   Date: ___________
```

### Key clauses explained

**Scope of services:**
Be specific about subjects and levels. "Algebra I tutoring" not just "math tutoring." This prevents scope creep where a parent expects calculus help when you agreed to algebra.

**Payment terms:**
Be explicit. "Payment is due at the start of each session" or "Monthly invoices are due within 7 days." Ambiguity leads to late payments.

**Cancellation policy:**
This is the most common source of conflict. Spell it out clearly. Consider: what counts as an emergency? What if the tutor cancels?

**Limitation of liability:**
You cannot guarantee grades. A student might improve but still get a C. Set expectations clearly in the contract.

**Termination clause:**
Either party should be able to end the relationship. Give yourself an out if it's not working.

## Online vs In-Person Proposals

### Online proposal considerations

```
Platform: [Zoom / Google Meet / other]
Tech requirements: Stable internet, camera, microphone, [digital whiteboard]
Materials: All materials provided digitally
Recording: [Recorded for review / not recorded]
Time zone: All times listed in [time zone]

Advantages to highlight:
- No travel time (more scheduling flexibility)
- Recorded sessions for review
- Digital tools for interactive learning
- Same quality as in-person
```

### In-person proposal considerations

```
Location: [Student's home / library / coffee shop / tutor's location]
Travel: Tutor/parent responsible for travel
Materials: Bring notebook, calculator, [materials student provides]
Duration: Includes travel time

Advantages to highlight:
- Personal connection
- Hands-on materials
- No tech issues
- Distraction-free environment
```

## Follow-Up Sequence

### After sending a proposal

**Day 1 — Send proposal:**
"I've attached the proposal for your review. Please let me know if you have any questions!"

**Day 3 — Gentle follow-up:**
"Hi [Name], just checking in on the proposal I sent. Happy to hop on a call if you'd like to discuss any details."

**Day 7 — Final follow-up:**
"Hi [Name], I want to make sure you have everything you need. The proposal is open-ended, but my schedule does fill up quickly. Let me know if you'd like to move forward or if there's anything I can clarify."

**Day 14 — Close (if no response):**
"Hi [Name], I haven't heard back so I'll assume the timing isn't right. Feel free to reach out in the future if you need math tutoring support. Wishing [Student] the best!"

### Objection handling

**"It's too expensive":**
- Break down per-session cost vs value
- Offer a smaller package (4 sessions instead of 8)
- Compare to cost of not tutoring (grade impact, summer school)
- Offer payment plan (split into 2 payments)

**"We need to think about it":**
- "I understand! What questions do you have?"
- "Would it help to do a trial session first?"
- "No pressure — just know my schedule fills up by [timeframe]"

**"Can you do [lower rate]?":**
- "My standard rate is $X, but I can offer a 10-session package at $X/session"
- "I can't lower my rate, but I can add [extra value: weekly check-ins, progress reports]"
- "Let me suggest a shorter session format at a lower total cost"
