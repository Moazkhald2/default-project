# Lesson Booking & Scheduling

Skill for setting up scheduling systems, managing availability, and handling bookings.

## When to Use

- User needs to set up a booking system
- User wants to manage their calendar efficiently
- User needs a cancellation policy
- User handles online and in-person sessions
- User needs automated reminders

## Booking Flow

```
1. INQUIRY ───→ 2. DISCOVERY CALL ───→ 3. TRIAL SESSION ───→ 4. REGULAR BOOKING
                    (15-20 min)           (first session)         (recurring)
```

### Google Calendar setup

1. Create a dedicated Google Calendar for tutoring
2. Color code: Blue = Tutoring, Red = Unavailable, Green = Available (if you use booking links)
3. Enable appointment slots for recurring availability
4. Set default reminder: 1 hour before (email + notification)
5. Share calendar view with clients (optional: show free/busy only)

### Calendly setup

1. Connect Google/Office 365 calendar
2. Set availability: Mon-Fri 3-7pm, Sat 9am-12pm
3. Create event types:
   - Discovery Call (15 min)
   - Trial Session (45 min)
   - Regular Session (60 min)
   - Group Session (90 min)
4. Set buffer time: 15 min between sessions
5. Add intake questions (grade, subject, goals)
6. Set minimum notice: 4 hours
7. Set cancellation policy link

## Availability Management

### Creating your schedule

**Calculate total available hours:**
```
Max sessions per week:  20-25 (to avoid burnout)
Session length:         60 min
Buffer between:         15 min
Travel time:            [add if in-person]
Prep time per session:  15-30 min
Admin time per week:    2-3 hours
```

**Sample weekly schedule:**
```
Monday:    3:00 PM - 7:00 PM  (4 sessions)
Tuesday:   3:00 PM - 5:00 PM  (2 sessions) 
Wednesday: 3:00 PM - 7:00 PM  (4 sessions)
Thursday:  3:00 PM - 5:00 PM  (2 sessions)
Friday:    3:00 PM - 6:00 PM  (3 sessions)
Saturday:  9:00 AM - 12:00 PM (3 sessions)
```

**Block time for:**
- Lesson prep (2-3 hours/week)
- Administrative (emails, billing, scheduling)
- Professional development
- Personal time (non-negotiable — avoid burnout)

## Session Types

### In-Person Sessions

**Considerations:**
- Travel time: add 15-30 min per session
- Travel cost: $0.655/mile or flat travel fee ($5-10)
- Location options: student's home, library, coffee shop, co-working space
- Safety: public places for first meetings, inform someone of location
- Materials: bring backup supplies (calculator, graph paper, dry-erase board)

**In-person costs to factor:**
```
Travel per session: $5-10 (gas + wear)
Time per session:   60 min session + 20 min travel each way = 100 min total
Effective rate:     $60 / 100 min = $36/hour (major difference!)
```

## Cancellation Policy

### Policy templates

**Standard (recommended):**
```
- 24 hours notice required for cancellation
- Late cancellation (< 24 hours): full session charged
- Emergency/illness: waived with same-day notice
- Tutor cancellation: session rescheduled or credited
- Make-up sessions: scheduled within 2 weeks, subject to availability
- No-show: full session charged
```

**Strict (high demand):**
```
- 48 hours notice required
- Late cancellation: full session charged
- No exceptions for make-ups
- 3 late cancellations = termination of contract
```

**Flexible (new tutors):**
```
- 12 hours notice required
- Late cancellation: 50% charge
- 2 free late cancellations per semester
- Make-ups offered within 1 week
```

### Communicating cancellation policy
- Include in welcome email
- Include in contract
- Link in booking confirmation
- Mention on discovery call
- Reiterate in first session

## Reminders

### Automated reminder sequence

```
24 hours before: Email — "Reminder: Session tomorrow at 3:00 PM"
2 hours before:   Text — "Looking forward to our session at 3:00 PM!"
15 min before:    — (you log on and wait)
```

### How to set up

**Calendly/Acuity:** Built-in reminders (email, SMS)
**Google Calendar:** Email + pop-up notifications
**Third-party:** Calendly, TimeTrade, Apptoto, Remind

**Manual (if no automation):**
- Night before: text parent "Confirming tomorrow at 3pm?"
- If no response by 1 hour before: call
- If no answer: send text "Hope everything's okay. Let me know if you need to reschedule."

## Time Zone Management

### Online students across time zones

**Best practices:**
- State your time zone in all communications: "All times are Eastern (ET)"
- Use tools: Calendly auto-detects time zones
- Confirm time zone during booking: "Just to confirm, 3:00 PM ET = 12:00 PM PT"
- Use dual-time clock widget on booking page
- Be clear about daylight saving changes

**Time zone reference table:**
```
ET → CT: -1 hour
ET → MT: -2 hours
ET → PT: -3 hours
ET → GMT: +4 hours (winter), +5 hours (summer)
ET → CET: +5 hours (winter), +6 hours (summer)
```

## Peak Seasons

### Calendar of demand

| Period | Demand | Strategy |
|--------|--------|----------|
| Back-to-school (Sep) | High | Promotion: "Fall semester kickoff" |
| Midterms (Oct-Nov) | Very High | Limit new students, prioritize existing |
| Finals (Dec) | Very High | Intensive packages, limited slots |
| Winter break (late Dec) | Medium | Exam prep workshops |
| Spring semester (Jan-Feb) | High | New student promotions |
| Spring break (Mar-Apr) | Medium | SAT/ACT bootcamps |
| AP/IB exams (May) | Very High | Lock schedules 2 months ahead |
| Finals (May-Jun) | Very High | Intensive packages |
| Summer (Jun-Aug) | Medium-High | Summer catch-up, enrichment, SAT prep |

### Planning for peak seasons

**2 months before peak:**
- Announce limited availability to existing clients
- Stop taking new clients (or cap at low number)
- Prepare materials and lesson plans

**During peak:**
- Consider 90-minute intensive sessions instead of 60-min
- Add weekend slots temporarily
- Raise rates for new clients (20% premium)

**After peak:**
- Take time off (schedule a recovery week)
- Review what worked and what didn't
- Adjust rates and availability
