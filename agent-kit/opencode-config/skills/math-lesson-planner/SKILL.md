# Math Lesson Planner

Skill for planning complete math lessons from hook to assessment.

## When to Use

- User asks "plan a lesson on [topic]"
- User needs a structured lesson for a specific grade level
- User is preparing to teach a math concept and needs a framework
- User needs differentiation strategies for diverse learners

## Lesson Structure

Every lesson follows this 6-part structure with suggested timing:

```
Total time: 45 / 60 / 90 minutes

1. Hook / Warm-Up        (5-10 min)
2. Direct Instruction     (10-15 min)
3. Guided Practice        (10-15 min)
4. Independent Practice   (10-15 min)
5. Assessment / Check-In  (5-10 min)
6. Closure / Exit Ticket  (3-5 min)
```

## Template

### Lesson Overview

```
Topic:           [concept name]
Grade Level:     [elementary | middle | high school | college]
Prerequisites:   [what students should already know]
Standards:       [CCSS, IB, Cambridge, etc.]
Materials:       [worksheets, manipulatives, tech tools]
Vocabulary:      [key terms]
```

### Stage 1: Hook / Warm-Up

Purpose: Activate prior knowledge, spark curiosity, surface misconceptions.

**Strategies by level:**

| Level | Hook Ideas |
|-------|-----------|
| Elementary | Number talks, math stories, pattern puzzles, "would you rather?" math |
| Middle | Estimation 180, Which One Doesn't Belong?, brain teasers |
| High School | Real-world data sets, counterintuitive results, "notice/wonder" |
| College | Historical context, paradoxes, application problems |

**Sample warm-up format:**
```
Warm-Up (5 min):
Solve: [problem]
Discuss with partner: [discussion prompt]
```

### Stage 2: Direct Instruction

Purpose: Introduce new concept with clear explanations and modeling.

**Structure:**
1. **I Do** — Model the concept. Think aloud. Show worked examples.
2. **Key Question** — Frame the learning: "By the end of this, you'll be able to..."
3. **Vocabulary** — Introduce terms with visual cues
4. **Multiple Representations** — Show concept as: symbolic, graphical, verbal, numerical

**Example for solving equations:**
```
Direct Instruction (12 min):
1. Define: equation, variable, solution, inverse operation
2. Model: Solve 2x + 3 = 11
   - Think aloud: "I want x alone. First, undo +3 with -3..."
3. Check: Substitute x = 4 back in: 2(4) + 3 = 11 ✓
4. Represent: Show balance scale metaphor
```

### Stage 3: Guided Practice

Purpose: Students try with teacher support. Catch errors early.

**Format:**
- 3-5 problems of increasing difficulty
- Students work on whiteboards or in pairs
- Teacher circulates and gives targeted feedback
- Pause after each problem to discuss common errors

**Scaffolding techniques:**
- Provide partially completed solutions (fill in blanks)
- Use "My turn / Your turn" pattern
- Sentence starters: "First I ____ because ____"
- Error analysis: "Which solution is correct? Why?"

### Stage 4: Independent Practice

Purpose: Students consolidate understanding on their own.

**Design principles:**
- 5-8 problems progressing in difficulty
- Include at least 1 application/word problem
- Include 1 challenge problem for early finishers
- Students can check answers with a partner when done

**Differentiation:**

| Student Need | Strategy |
|-------------|----------|
| Struggling | Fewer problems, scaffolded versions, worked example reference |
| At grade level | Standard set, one extension |
| Advanced | Open-ended problems, create-your-own, prove a generalization |

### Stage 5: Assessment / Check-In

Purpose: Gauge understanding before independent work ends.

**Formative assessment techniques:**
- 2-3 quick check problems
- Thumbs up/middle/down
- Mini-whiteboard show
- One-paragraph reflection: "What was easy? What was tricky?"
- 3-2-1: 3 things I learned, 2 questions I have, 1 thing I'm unsure about

### Stage 6: Closure / Exit Ticket

Purpose: Consolidate learning, preview next topic, inform next lesson.

**Exit ticket template:**
```
Name: _________________________

1. Today I learned...
2. One question I still have...
3. Rate your understanding: 😊 😐 😟
```

**Closure activities:**
- Student summarizes the main idea in one sentence
- "What's the most important thing to remember?"
- Connect to previous learning: "How does this connect to what we did last week?"
- Preview: "Tomorrow we'll use this to..."

## Homework Design

**Guidelines:**
- 15-20 minutes max for elementary
- 20-30 minutes for middle school
- 30-45 minutes for high school
- Always include at least one review problem from previous topic
- Include one preview problem for next topic
- Provide answer key for self-check

## Differentiation Strategies

### For struggling students:
- Pre-teach vocabulary before the lesson
- Provide graphic organizers
- Use concrete manipulatives before abstract symbols
- Allow extra time on independent practice
- Pair with a strong peer (strategic pairing)
- Provide checklist of steps

### For advanced students:
- Open-ended exploration: "What if we changed...?"
- Prove a generalization
- Create a teaching video explaining the concept
- Design their own problems
- Connect to real-world applications beyond the standard

## Example Lesson Plan (60 min)

```
Lesson: Solving Two-Step Equations
Grade: 7th Grade (Pre-Algebra)
Standard: CCSS 7.EE.B.4a
Prerequisites: One-step equations, integer operations

Materials: Whiteboards, markers, worksheet, balance scale app

Vocabulary: equation, variable, coefficient, constant, inverse operation

Warm-Up (7 min):
- Solve: x + 5 = 12, 3x = 18, x/4 = 6
- Discussion: "What does 'inverse operation' mean?"

Direct Instruction (15 min):
- Model 3x + 2 = 14 with balance scale
- "Undo addition first, then multiplication"
- Check answer by substitution
- Model second example: x/3 - 1 = 4

Guided Practice (13 min):
- Problem 1: 2x + 5 = 13 (together)
- Problem 2: 4x - 3 = 9 (pairs, check with group)
- Problem 3: x/2 + 3 = 7 (individual, teacher circulates)
- Error analysis: Show incorrect work, find mistake

Independent Practice (13 min):
- 6 problems: 2x + 7 = 15, 3x - 4 = 11, x/5 + 2 = 6, etc.
- Word problem: "Kelly bought 3 notebooks and a $2 pen. Total was $11. How much per notebook?"
- Challenge: 2(x + 3) = 14

Exit Ticket (7 min):
- Solve: 5x - 3 = 22
- One thing I'm confident about: _____
- One thing I need more help with: _____

Homework:
- 10 two-step equations
- 1 word problem
- 1 review: one-step equations
- 1 preview: what happens when variable is on both sides?
```
