# Client Management for Math Tutors

Skill for managing student intake, progress tracking, communication, and retention.

## When to Use

- User needs an intake process for new students
- User wants to track student progress
- User needs templates for parent communication
- User wants to improve client retention
- User wants to set up a CRM system

## Intake Process

### Step 1: Inquiry (first contact)

**Questions to ask:**
```
Student name, grade, school:
What subject(s) need help?
What is the current grade/performance?
What are the specific concerns? (struggling, test prep, enrichment)
What are your goals for tutoring?
Preferred schedule:
In-person or online?
How did you hear about me?
```

### Step 2: Discovery call (15-20 min)

**Structure:**
```
1. Listen to concerns (5 min) — Let parent/student talk first
2. Ask about history (3 min) — Previous tutoring, learning differences
3. Assess fit (5 min) — Can you help? Are they serious?
4. Logistics (3 min) — Schedule, rate, commitment
5. Next steps (2 min) — Trial session, booking
```

**What to assess during the call:**
- Student's attitude (motivated, resistant, anxious)
- Parent's involvement (supportive, helicopter, absent)
- Urgency (cramming, long-term support, enrichment)
- Fit with your expertise (can you actually help?)

### Step 3: Trial session (first session)

**Structure:**
```
First 5 min: Rapport building, get to know the student
Next 15 min: Diagnostic assessment (3-5 problems at current level)
Next 15 min: Work through a problem together
Next 10 min: Assessment of learning style and gaps
Last 5 min: Recap and next steps
```

**After trial session:**
- Note student's strengths and weaknesses
- Assess personality fit and communication style
- Decide whether to continue
- Follow up with parent within 24 hours

## Retention Strategies

### Keep students coming back

**First month focus:**
- Respond to all messages within 2 hours
- Send session summary after each session
- Show visible progress (even small wins)
- Build rapport with both student and parent

**Ongoing:**
- Celebrate milestones (first A, concept mastered, grade improvement)
- Send seasonal greetings (holidays, back-to-school)
- Check in during breaks (don't just disappear)
- Ask for feedback at end of semester
- Offer referral incentives

**Red flags (at-risk of leaving):**
- Student seems bored or disengaged
- No improvement after 6 sessions
- Parent stops responding to messages
- Multiple cancellations in a row
- Complaints about price (without mentioning value)

**Retention actions:**
- Change approach (different teaching style, new materials)
- Have honest conversation about goals
- Offer adjusted schedule or package
- Provide additional resource for practice between sessions

## Difficult Situations

### Unmotivated student
- Find connection: what do they care about? Games? Sports? Music? Link math to it.
- Build confidence: start with easy problems they can succeed at
- Change format: 15 min work, 2 min break, repeat
- Set micro-goals: "Let's do 3 problems, then we'll talk about [their interest]"
- Involve parent: discuss expectations and consequences

### Demanding parent
- Set boundaries early: response time expectations, session observation policy
- Document everything: session notes, progress, communications
- Focus on facts: "Your child has improved from 65% to 78% on quizzes"
- Have a script: "I understand your concern. Here's what I'm doing about it..."
- Know when to fire: if unreasonable demands continue, professionally end the relationship

### Schedule conflicts
- Have a clear cancellation policy in writing
- Offer one make-up per month at no charge
- Use a booking tool (Calendly) to reduce back-and-forth
- For chronic cancellers: move to pay-per-session or require pre-paid package

### Student not improving
- Re-assess: are we working on the right things?
- Check fundamentals: is there a prerequisite skill gap?
- Change approach: visual, hands-on, real-world application
- Reduce scope: master fewer topics deeply
- Communicate with parent honestly about timeline
- Consider referral: if not a good fit, recommend another tutor
