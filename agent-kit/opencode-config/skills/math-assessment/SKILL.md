# Math Assessment Creator

Skill for designing formative and summative math assessments with rubrics.

## When to Use

- User needs a quiz or test on a math topic
- User wants to create a diagnostic assessment
- User needs a rubric for grading
- User wants to analyze assessment results
- User needs accommodations for diverse learners

## Assessment Types

### Diagnostic (pre-test)
- Administered before instruction
- Identifies prior knowledge and gaps
- Covers prerequisites for upcoming unit
- Low stakes, no grade
- Result: informs lesson planning

### Formative (during learning)
- Checks understanding during instruction
- Examples: exit tickets, quick checks, warm-ups, observations
- Low stakes, feedback-focused
- Result: informs next teaching moves

### Summative (end of unit)
- Measures mastery of learning objectives
- Examples: unit test, final exam, project
- Higher stakes, graded
- Result: determines proficiency level

### Benchmark (periodic)
- Measures progress toward long-term goals
- Given at regular intervals (quarterly, semester)
- Standardized format for comparison
- Result: tracks growth over time

## Test Structure

### Difficulty progression
```
Easy (30%):    Direct recall, single step
Medium (50%):  Multi-step, routine application
Hard (20%):    Non-routine, requires strategy
```

### Point distribution

| Question Type | Points | Section |
|--------------|--------|---------|
| Multiple choice | 2-4 each | Section A |
| Short answer | 4-6 each | Section B |
| Open-ended | 8-12 each | Section C |
| Extended response | 15-20 each | Section D |
| Bonus/challenge | 5-10 | Optional |

### Time allocation

| Test Length | Recommended Time |
|-------------|-----------------|
| 10 questions | 20-25 minutes |
| 20 questions | 40-50 minutes |
| 30 questions | 60-75 minutes |
| 40+ questions | 90-120 minutes |

Rule of thumb: 2-3 minutes per multiple choice, 5-8 minutes per open-ended.

## Question Design

### Writing clear questions

**DO:**
- Use grade-appropriate vocabulary
- Define non-math terms that might be unfamiliar
- State exactly what's expected ("Show all work" or "No calculator")
- Include units in answer expectations
- One clear correct answer (for objective items)

**DON'T:**
- Use double negatives
- Include irrelevant information that distracts
- Use ambiguous wording
- Test reading comprehension when assessing math
- Have "all of the above" / "none of the above" patterns

### Multiple choice design

```
Good:
Which of the following is equivalent to 2(x + 3) - 4?
A) 2x - 1
B) 2x + 2
C) 2x + 10
D) 2x - 10
Answer: B

Distractor analysis:
A) Misapplies distribution: 2(x + 3) - 4 = 2x + 3 - 4 → 2x - 1 ✗
C) Forgets to subtract 4: 2(x + 3) = 2x + 6, then +4 instead of -4 ✗
D) Distributes negative incorrectly ✗
```

### Open-ended questions

```
Solve and show your work:
2(x - 3) + 5 = 3(x + 1) - 4

Rubric:
- Distributes correctly (2 points)
- Combines like terms correctly (2 points)
- Moves variables to one side correctly (2 points)
- Solves for x correctly (2 points)
- Checks solution (2 points)
Total: 10 points
```

## Rubric Design

### Analytic rubric (scored by criteria)

```
Topic: Solving Linear Equations

| Criteria | 4 (Exemplary) | 3 (Proficient) | 2 (Developing) | 1 (Beginning) |
|----------|---------------|----------------|----------------|----------------|
| Concept understanding | Explains reasoning clearly | Shows understanding | Partial understanding | Does not understand |
| Procedure | All steps correct, efficient | Minor errors | Major errors | No correct steps |
| Accuracy | 100% correct | 80%+ correct | 50%+ correct | <50% correct |
| Communication | Clear notation, organized | Mostly clear | Some organization | No organization |
```

### Holistic rubric (single score)

```
Score 4: Complete understanding demonstrated. All work shown, correct answer,
         clear reasoning. No errors.

Score 3: Good understanding with minor errors. Work is mostly correct
         but has small computational or procedural mistakes.

Score 2: Partial understanding. Some correct steps but significant errors
         or incomplete work.

Score 1: Minimal understanding. Attempted but few correct elements.

Score 0: No attempt or completely incorrect.
```

### Single-point rubric (feedback-focused)

```
Topic: Graphing Linear Equations

| Areas for Improvement | Standard | Exceeds Expectations |
|----------------------|----------|---------------------|
| | Plot points correctly | |
| | Draw line through points | |
| | Label axes and title | |
| | Interpret slope and intercept | |
```

## Assessment Analysis

### Item difficulty index
```
Difficulty = (Number of correct responses) / (Total responses)

Ideal range: 0.4 - 0.8
Too easy: > 0.9 (consider replacing)
Too hard: < 0.3 (consider revising or removing)
```

### Discrimination index
```
D = (High group correct - Low group correct) / (Number of students per group)

Top 27% = high group, Bottom 27% = low group
Ideal: D > 0.4
Needs revision: 0.2 - 0.4
Weak: D < 0.2
```

### Distractor analysis
For each distractor in a multiple choice question:
- Good distractor: chosen by at least 5% of students
- Weak distractor: chosen by < 5%, consider replacing
- Check if high-performing students are choosing distractor (indicates confusing wording)

## Accommodations

### Time and environment
- Extended time (1.5x, 2x)
- Separate setting (quiet room)
- Breaks as needed
- Read-aloud accommodation

### Presentation
- Large print (18pt+)
- One question per page
- Simplified language (remove complex sentence structures)
- Visual supports (number lines, formula sheets)

### Response
- Scribe (student dictates, someone writes)
- Calculator accommodation
- Word bank
- Reduce number of problems (quality over quantity)

### Examples by difficulty

**Mild accommodation:** extended time, separate setting
**Moderate accommodation:** reduced problems, simplified language
**Extensive accommodation:** read-aloud, scribe, formula sheet, one-on-one administration

## Assessment Templates

### Exit Ticket
```
Topic: [topic]              Name: ____________

1. What is [key concept]?
2. Solve: [1 problem]
3. Rate your understanding: 1 2 3 4 5
4. What are you still confused about?
```

### Quiz (15-20 min)
```
Quiz: [Topic]                          Total: ___/20

Part A: Multiple Choice (3 @ 2 pts each = 6 pts)
Part B: Short Answer (2 @ 4 pts each = 8 pts)
Part C: Problem Solving (1 @ 6 pts)

Time: 15 minutes
```

### Unit Test (45-60 min)
```
Unit [X] Test: [Topic]                      Total: ___/50

Part A: Multiple Choice (5 @ 2 pts = 10)
Part B: Short Answer (4 @ 4 pts = 16)
Part C: Extended Response (2 @ 8 pts = 16)
Part D: Challenge (1 @ 8 pts = 8) [Extra Credit]

Calculator Allowed for Parts C & D only.
Show all work for Parts B, C, D.
```

### Final Exam (90-120 min)
```
Final Exam: [Course]                    Total: ___/100

Section 1: Multiple Choice (20 @ 2 pts = 40)
Section 2: Short Answer (6 @ 5 pts = 30)
Section 3: Extended Response (3 @ 10 pts = 30)

Calculator policy: [specify]
Formula sheet: [provided / not provided]
Passing score: 60
```

## Feedback Guidelines

### Good feedback is:
- **Specific**: "You distributed correctly but made an arithmetic error when combining like terms" not "Check your work"
- **Timely**: Within 24-48 hours
- **Actionable**: Tells student what to do next
- **Growth-oriented**: "You can improve by checking your solution by substitution"
- **Encouraging**: Acknowledge what was done correctly first

### Feedback sentence starters:
- "One thing you did well was..."
- "Next time, try..."
- "Check your work at step [X] where..."
- "Think about what happens when you..."
- "How could you verify your answer?"

## Output

When creating an assessment, return:
1. Complete assessment with clear instructions
2. Time allocation and point distribution
3. Answer key with full solutions
4. Rubric (analytic, holistic, or single-point)
5. Accommodation suggestions
6. Analysis guidelines for scoring
