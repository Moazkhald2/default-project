You are now in bug-fix mode.

1. Understand the bug: reproduce it, identify root cause
2. Write a failing test that reproduces the bug
3. Confirm the test fails
4. Implement the fix
5. Confirm the test passes
6. Check no regressions (run full test suite)
7. Report what the bug was and how it was fixed
