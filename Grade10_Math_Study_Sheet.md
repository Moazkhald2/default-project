## 📄 LESSON 1 — Complex Numbers & Quadratic Equations

**The Lib you do:**
- Identify type of roots using Δ = b² − 4ac
- Solve quadratic equations using x = (−b ± √Δ) / 2a
- Distinguish real numbers from complex (imaginary) numbers
- Write complex numbers in form a + bi
- Determine if roots are rational or irrational based on Δ

**The Lib you memorise:**
- Standard form: ax² + bx + c = 0 (a ≠ 0)
- Discriminant: Δ = b² − 4ac
- Δ > 0 → two distinct real roots
- Δ = 0 → two equal real roots
- Δ < 0 → two complex roots
- Quadratic formula: x = (−b ± √Δ) / 2a
- Imaginary unit: i² = −1
- i³ = −i, i⁴ = 1
- Complex number form: a + bi
- Sum of roots (α + β) = −b/a
- Product of roots (α × β) = c/a
- If Δ is a perfect square → roots are rational
- If Δ > 0 but not a perfect square → roots are irrational

## 📄 LESSON 2 — Functions & Inequalities

**The Lib you do:**
- Determine sign of constant, linear, and quadratic functions
- Sketch the graph of a quadratic function
- Solve quadratic inequalities (f(x) > 0 or f(x) < 0)
- Find domain and range of a function
- Identify vertex of a parabola

**The Lib you memorise:**
- Constant function: f(x) = c → horizontal line
- Linear function: f(x) = ax + b → straight line
- Quadratic function: f(x) = ax² + bx + c → parabola
- If a > 0 → parabola opens upward (U-shape)
- If a < 0 → parabola opens downward (∩-shape)
- Between roots of upward parabola → f(x) < 0
- Outside roots of upward parabola → f(x) > 0
- Vertex x-coordinate: x = −b / 2a
- Vertex y-coordinate: f(−b/2a)
- Domain of any polynomial = all real numbers ℝ
- If a > 0 → range = [minimum value, ∞)
- If a < 0 → range = (−∞, maximum value]
- f(x) > 0 → function above x-axis
- f(x) < 0 → function below x-axis

## 📄 LESSON 1 — Similarity of Triangles & Polygons

**The Lib you do:**
- Determine the coefficient of similarity (k)
- Apply similarity to triangles and polygons
- Calculate the ratio of areas between similar figures
- Prove two triangles are similar
- Find missing side lengths using k

**The Lib you memorise:**
- Similar = same shape, different size
- Corresponding angles are equal
- Corresponding sides are proportional
- Coefficient of similarity: k = side (image) / side (original)
- k > 1 → enlargement, k < 1 → reduction, k = 1 → congruence
- Ratio of areas = k²
- Ratio of perimeters = k
- AA criterion: two angles equal → triangles similar
- SAS criterion: two sides proportional + included angle equal → similar
- SSS criterion: three sides proportional → similar
- All corresponding heights, medians, angle bisectors also in ratio k
- Ratio of areas of similar polygons = k²

---

## 📄 LESSON 2 — Proportionality Theorems in Triangles

**The Lib you do:**
- Apply Thales' theorem with parallel lines cutting triangle sides
- Apply the internal and external angle bisector theorem
- Use proportionality in circles (intersecting chords, secants, tangents)
- Prove segments are proportional
- Solve for unknown segment lengths

**The Lib you memorise:**
- Thales' theorem: If DE ∥ BC → AD/DB = AE/EC
- Internal angle bisector: BD/DC = AB/AC
- External angle bisector: BD/DC = AB/AC (divides externally)
- Intersecting chords: AE × EB = CE × ED
- Secant from external point: PA × PB = PC × PD
- Tangent-secant: PT² = PA × PB
- Angle at centre = 2 × angle at circumference (same arc)
- Angles in the same segment of a circle are equal
- Tangent is perpendicular to radius at point of contact

## 📄 LESSON 1 — Angles & Trigonometric Ratios

**The Lib you do:**
- Convert between degrees and radians
- Define sin, cos, and tan using a right triangle
- Identify directed angles (positive = counterclockwise, negative = clockwise)
- Calculate trig ratios for special angles (30°, 45°, 60°)
- Use the unit circle to find trig values

**The Lib you memorise:**
- 180° = π radians
- 360° = 2π radians
- 90° = π/2, 45° = π/4, 30° = π/6, 60° = π/3
- sin θ = opposite / hypotenuse (SOH)
- cos θ = adjacent / hypotenuse (CAH)
- tan θ = opposite / adjacent (TOA)
- Unit circle: point on circle = (cos θ, sin θ)
- Directed angle: positive = counterclockwise, negative = clockwise
- Any angle can be written as θ + 360°n (or θ + 2πn)
- Pythagorean identity: sin²θ + cos²θ = 1
- tan θ = sin θ / cos θ
- sin(90° − θ) = cos θ
- cos(90° − θ) = sin θ

**Special Angle Table:**

| Angle | sin | cos | tan |
|-------|-----|-----|-----|
| 0° | 0 | 1 | 0 |
| 30° | 1/2 | √3/2 | 1/√3 |
| 45° | √2/2 | √2/2 | 1 |
| 60° | √3/2 | 1/2 | √3 |
| 90° | 1 | 0 | undefined |

## 📄 LESSON 2 — Graphs & Associated Angles

**The Lib you do:**
- Sketch graphs of y = sin x, y = cos x, y = tan x
- Determine the period of any trigonometric function
- Find an angle given one of its trig ratios
- Use associated angle identities to simplify expressions
- Evaluate inverse trig functions (sin⁻¹, cos⁻¹, tan⁻¹)

**The Lib you memorise:**
- Period of sin x = 2π (360°)
- Period of cos x = 2π (360°)
- Period of tan x = π (180°)
- Period of sin(bx) = 2π/b
- Period of tan(bx) = π/b
- sin(−θ) = −sin θ (odd function)
- cos(−θ) = cos θ (even function)
- tan(−θ) = −tan θ (odd function)
- sin(π − θ) = sin θ
- cos(π − θ) = −cos θ
- sin(π + θ) = −sin θ
- cos(π + θ) = −cos θ
- sin(2π − θ) = −sin θ
- cos(2π − θ) = cos θ
- y = sin x key points: (0°,0) → (90°,1) → (180°,0) → (270°,−1) → (360°,0)
- y = cos x key points: (0°,1) → (90°,0) → (180°,−1) → (270°,0) → (360°,1)
- y = tan x has vertical asymptotes at x = 90° + 180°n
- sin²θ + cos²θ = 1
- 1 + tan²θ = sec²θ
- 1 + cot²θ = csc²θ
