The circle with centre $O$ has chord $AB$. If $\angle AOB = 80\degree$, find the inscribed angle $\angle ACB$ subtended by the same arc $AB$.

Figure: use `assets/geometry_templates/circle-inscribed-angle.svg` for print, `materialId: R4kXz7Mv` for web interactive.

Answer: $40\degree$ — the inscribed angle is half the central angle.
